# Adem v1.0.0

The first public release of Adem, a calm local Linux process dashboard.

Highlights:

- Live CPU, RAM, swap, storage and process metrics.
- Search, filter and multi-select recognised desktop apps.
- Review-first close flow with identity revalidation and a single-use expiry.
- Browser, agent sessions, password managers, recording software and unknown processes protected.
- English responsive interface with keyboard and reduced-motion support.
- MIT license, GitHub Actions tests and issue templates.
